# Custom Local Lyrics Directory (.lrc)

Taruh file lirik `.lrc` kustom kamu di folder ini!
Miniplayer akan otomatis memprioritaskan file `.lrc` lokal sebelum mencari ke internet.

### Format Penamaan File yang Didukung:
1. `Judul Lagu.lrc` (Contoh: `Sambutlah.lrc`)
2. `Artis - Judul Lagu.lrc` (Contoh: `Denada - Sambutlah.lrc`)
3. `Judul Lagu - Artis.lrc` (Contoh: `Sambutlah - Denada.lrc`)
